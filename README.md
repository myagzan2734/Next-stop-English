# Next Stop

Sıfırdan C1’e İngilizce çalışma uygulaması: günlük rota, aralıklı kelime tekrarı, dikte, sesli tekrar, cümle makinesi ve sınavlar.

Tüm alıştırmalar, metinler ve sınavlar özgün olarak yazılmıştır. A1–B1 hatlarının ünite sırası, kursta Speakout 2nd Edition kullananlar takip edebilsin diye o kitapların programıyla uyumludur; kitaplardan metin ya da ses içermez. Bu proje Pearson ile bağlantılı değildir.

Güncelleme yaparken `sw.js` içindeki `CACHE` sürüm adını değiştirmeyi unutma.
